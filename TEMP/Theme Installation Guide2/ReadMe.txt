/*********************************************** WaliSystems *******************************************/
1) Install wordpress in your hosting panel.

2) login to wordpress admin dashboard.

=========================================Themes Installation==================================

3) Go to Apprearance > Themes > add new > upload Theme. Choose theme file in themes directory upload and active it.

=========================================Plugin Installation==================================

4) Go to Plugins > Add new > Upload Plugin.upload plugins from plugins directory and active it.

=========================================Import data==================================

5) Go to Tools > Import > Wordpress Importer and import file from importer directory. 

Notice: Move Uploads folder to wp-content directory in your cpanel.
